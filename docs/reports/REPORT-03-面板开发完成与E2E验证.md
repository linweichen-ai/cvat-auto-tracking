# REPORT-03 自助标注面板开发完成 + 端到端验证通过

## ① 本节点结论
**核心功能已经跑通并通过端到端验证**：在已有的 SAM3 跟踪后端基础上，我们做了一个嵌入 CVAT 标注页的中文悬浮面板，标注员现在可以在作业页里"手动标前几帧 → 一键自动传播后续帧"。全部测试只在 Demo 任务上做，真实任务零改动，且已干净回滚。GitHub 推送阻塞也已解决，代码正在入库。

## ② 关键事实
- **两种使用方式**：① Tampermonkey 单文件用户脚本；② Manifest V3 浏览器扩展（Edge/Chrome 开发者模式加载）。打开任意作业页，右上角自动出现中文面板，自动识别当前 Job 和帧号，自动复用浏览器登录会话，无需额外登录。
- **标注员工作流**：手动标注前几帧并保存 → 选标签、填帧范围 → 点「缓存帧」（带进度条）→ 点「范围自动跟踪」，模型把首帧实例形状逐帧传播到结束帧 → 跳转过去检查即可。
- **端到端验证全绿**：在 DemoTask（job 419）上先备份 24 个标注 → 缓存 → 对一个 pallet 实例从 frame0 传播到 frame1，成功新增 1 个 shape → 已干净回滚，恢复后 24 个 shape、分帧分布与备份完全一致。
- **真实页面实测**：面板在真实 CVAT 页面完整渲染，截图存 `results\panel-render.png`。
- **GitHub**：classic token 已验证可写，推送阻塞解除，DevOps 正在把全部代码与文档推送入库。

## ③ 问题与风险
- sessionid 是 HttpOnly Cookie：扩展用 `chrome.cookies` 自动读取、用户脚本用 `GM_cookie`，两条路都失败时面板支持手动粘贴，不影响使用。
- 踩过一个坑：CVAT 的 DELETE 整份标注接口会**清空整个 Job**（测试中误删一次，已用备份恢复）；后续回滚统一用整份 PUT，不再碰 DELETE。真实任务全程未动。
