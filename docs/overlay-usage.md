# CVAT 自助标注面板 —— 标注员使用手册

对接后端：SAM3 CVAT Tracker（`http://172.16.88.68:11089`），CVAT `http://172.16.88.68:12080`。

## 一、安装（二选一）

### 方式 A：Tampermonkey 用户脚本
1. 浏览器安装 Tampermonkey 扩展。
2. 打开 Tampermonkey 管理面板 → 「实用工具」→ 导入 `userscript/cvat-auto-annotation.user.js`
   （或直接新建脚本，把整个文件内容粘贴进去并保存）。
3. 刷新 CVAT 页面即可。

### 方式 B：浏览器扩展（推荐，无需 TM）
1. Edge/Chrome 打开 `edge://extensions`（或 `chrome://extensions`），开启「开发者模式」。
2. 「加载解压的扩展」→ 选择项目里的 `extension/` 目录。
3. 刷新 CVAT 页面。

> 两种方式都**不需要重新输入 CVAT 账号密码**：面板自动复用你浏览器里已登录的 CVAT 会话。
> 前提：先正常登录 CVAT 并打开一个标注作业页。

## 二、日常标注流程（核心三步）

面板在页面右上角，深色悬浮卡片，可拖动、可点「—」折叠。顶部两行显示连接状态：

- `CVAT:leonlee233` / `SAM3:已连接`（绿色）= 正常。
- 若显示红色，先确认已登录 CVAT，再点面板里「连接/凭据 → 重新检测连接」。

**第 1 步：手动标前几帧**
在 CVAT 里像平时一样，把起始帧（比如第 0 帧）每个要跟踪的实例都标好（mask/多边形均可）。
切到下一帧时**按 `Ctrl+S` 保存一次**。

**第 2 步：缓存帧**
1. 在面板「标签」下拉选目标标签（如 `pallet`）。
2. 「帧范围」填起止帧，例如 `0 → 3`；或点「起点=当前 / 终点=当前」快速填入。
3. 点 **① 缓存帧**，进度条走到 `x/x 已就绪` 即完成。

**第 3 步：范围自动跟踪**
1. 「实例」下拉默认「全部（按标签）」= 自动跟踪起始帧上该标签的每一个实例；
   也可只选某一个实例单独跟踪。
2. 点 **② 范围自动跟踪** → 弹窗确认（确认你已 Ctrl+S 保存）后开始。
   状态栏会逐个实例显示进度 `实例 2/6（shape #xxx）`，请勿关闭页面。
3. 完成后点 **③ 跳转结束帧检查**，逐帧核对自动生成的标注，错的手动改。

> 工作流本质：**人标前几帧 → 点一次 → 后续帧自动完成**。

## 三、其他按钮

| 按钮 | 作用 |
|---|---|
| 传播下一帧 | 把当前选中实例从当前帧传到下一帧（微调时用） |
| 撤销上一步 | 调后端 `undo_last`，撤销最近一次写操作 |
| 改标签 | 把帧范围内某标签的全部 shape 改成另一个标签（二次确认） |
| 删范围 | 删除帧范围内某标签的全部 shape（二次确认，谨慎） |
| 提示分割 | 用点/框/文本提示在当前帧分割新实例（坐标手动输入，每行一个） |
| 清缓存 | 清空后端内存帧缓存（换任务/显存紧张时用） |

## 四、FAQ

**Q：面板没出现？**
确认打开的是标注作业页（URL 形如 `/tasks/426/jobs/419`），不是任务列表页。
按 F12 看 Console 有无红色报错，刷新一次页面。

**Q：状态显示「无会话 / CVAT:会话失效」？**
sessionid 是 HttpOnly Cookie。扩展方式一般自动读取；用户脚本若 TM 版本不支持
`GM_cookie`，展开「连接/凭据」，按提示从 F12 → Application → Cookies 复制
`sessionid` 粘贴进去，再点「重新检测连接」。

**Q：点了跟踪但没生成？**
- 先确认起始帧上确实有该标签的实例（「实例」下拉里能看到 #id）。
- 确认已点「缓存帧」且进度走完。
- 看状态栏红字报错，常见原因：后端忙、帧未缓存、标签选错。

**Q：跟踪后画面里看不到新标注？**
后端是直接写进 CVAT 数据库的，CVAT 页面内存里不知道。点「跳转结束帧检查」
（或刷新页面）即可看到。**刷新前请先 Ctrl+S 保存你手改的内容**。

**Q：可以在真实任务（CS_real*）上用吗？**
可以，工作流一样。但「删范围 / 改标签」会批量写标注，操作前务必二次确认弹窗；
建议先在 DemoTask（task 426 / job 419）练手。
