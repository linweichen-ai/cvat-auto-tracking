## 二、关键视频结构（重要发现）

该视频由**两个独立视频流交错合并**而成：

- **偶数帧（0,2,4…148）**：一个拍摄序列（仓库一侧）
- **奇数帧（1,3,5…149）**：另一个拍摄序列（仓库另一侧）

两个序列内部均有连续的场景切换（叉车在仓库中移动、靠近不同托盘）。SAM3 传播时在同序列的连续帧上匹配成功，跨序列（画面突变）时自动停止，因此需要在每个新场景的起始帧重新播种。

## 五、复现 / 回滚

- 完整标注备份：`results/full-propagation/job423-full-annotations.json`（492 形状）
- 标注员工作流：手动标注起始帧并 Ctrl+S → 选标签、填帧范围 → 「缓存帧」→ 「范围自动跟踪」→ 跳转结束帧检查
- 安装方式：Tampermonkey 用户脚本（`userscript/`）或 MV3 扩展（`extension/`）

## 六、注意事项

- SAM3 后端的 propagate 写回基于 CVAT 全量 PUT 语义，**跨场景多次传播会互相覆盖**；正确做法是一次性在各场景播种后统一传播，或每次传播后用 CVAT API 合并。
- 浏览器页面在大量操作后可能显示旧的标注计数（缓存），刷新页面即可恢复；以服务器端数据（GET /api/jobs/423/annotations）为准。
